# be-DailyJob 

> 이 회고는 작업량을 보고하기 위한 문서가 아니라, 
> 오늘 내가 어떤 판단을 했고 어떤 개발 행동을 반복하거나 바꿔야 하는지 확인하기 위한 기록입니다. 
> 각 항목은 길게 쓰기보다, 사실/판단/근거/다음 행동이 드러나게 구체적으로 작성하세요.

### 1. 오늘 완료한 것
- 오늘 실제로 끝낸 기능/수정/학습:
  - AWS S3에 putObject를 할 수 있는 IAM policy와 role를 설정해 백엔드 EC2에 할당했다.
  - S3 presignedURL을 발급하는 API를 구현했다. 프론트엔드에서 백엔드를 거치지 않고 S3로 파일을 업로드하기 위한 주소이다. 이중으로 들어가는 트래픽을 없앤다.
  - SSH로 EC2에 접속해 S3 presignedURL 발급과 업로드 권한이 있는지 확인했다.
  - 공통 schema.sql과 로컬 MySQL을 동기화 하는 스크립트를 생성했다.
- (오늘의 목표 중에서) 아직 끝내지 못한 부분:
  - notification에서 eventListener를 구현하지 못했다.
  - 브라우저에 알림을 띄우는 방법을 조사하지 못했다.

### 2. 오늘 가장 의미있었던 기술적 판단
- 함께 내린 판단: jwt를 사용한 SSE 연결을 EventSource Web API를 사용하기로 했다.
- 그렇게 판단한 이유: 
  - 백엔드에서 관리할 코드가 조금 늘어난다. JWT + 티켓관리
  - 프론트 코드가 복잡해지는 것보단 낫다
- 고려했지만 선택하지 않은 대안: 
  - 프론트엔드에서 fetch로 jwt 토큰을 포함해서 연결 요청.
    - 프론트에서 관리할 코드가 늘어나고, EventSource의 기능을 직접 구현해야 한다.
    - 기존 백엔드 JWT 인증 로직을 그대로 사용할 수 있다.
  - URL에 JWT토큰을 넣어서 SSE 연결 수립
    - 보안상 JWT 토큰이 그대로 노출된다는 심각한 문제가 발생한다.
- 이 판단이 코드 품질/테스트/유지보수에 미친 영향:
  - SSE 연결 관련 코드는 대부분 백엔드에서 관리하므로 유지보수가 편하다.

### 3. 가장 막혔던 문제와 해결 과정
- 문제 상황 또는 증상: 로컬 DB를 schema와 동기화 하는 스크립트가 작동을 안했다.
- 처음 추측한 원인: DB를 안켰거나, 비밀번호가 잘못됐거나
- 원인을 확인하기 위해 시도한 방법:
  - .env 파일 내용을 확인하고, DB가 켜졌는지 확인
  - 환경변수 값을 직접 주고 실행 -> 잘 됐음.
- 실제 원인: env 파일 로드하는 로직이 없어서 환경변수값이 설정이 안됨
- 해결 방법: env 파일 찾는 스크립트 추가하고, while로 line을 읽기 때문에 마지막 개행이 없는 파일에 대해서도 읽을 수 있게 처리를 했다.
- 다음에 비슷한 문제가 생기면 먼저 확인할 것: 기초적인 것부터 체크하자

### 4. 오늘 잘한 행동(개발과 관련된 것)
- 어떤 행동이었는지: 코드 개발 계획을 AI를 사용해 문서로 작성해 레포에 포함시켰다.
- 그 접근이 도움이 된 이유: 코드의 의도를 팀원들에게 쉽게 공유할 수 있고, AI가 작업할 때 레퍼런스로 사용할 수 있으며, 내 코드를 이해하는 데에도 도움이 된다.
- 다음에도 반복하고 싶은 점: 플랜 문서를 마구마구 작성하고 공유하자.

### 5. 오늘 아쉬웠던 행동(개발과 관련된 것)
- 비효율적이었던 접근/놓치거나 부족했던 점: PR하고 머지할 때 팀 컨벤션과 맞지 않아서 깃 그래프가 꼬였었다. 해결 방법을 몰라서 팀원들이 다시 처리해줬다.
- 그렇게 된 원인: fetch, rebase, pull, merge의 정확한 동작에 대한 이해가 부족했고, 팀 컨벤션을 구체적으로 숙지하지 않았다.
- 다음에는 다르게 해볼 구체적인 행동: git fetch, pull, rebase, merge에 대한 추가학습을 진행했다. 이제는 기억한다
  - git checkout feature_branch
  - git fetch
  - git rebase origin/dev
  - git push origin feature_branch --force-with-lease
  - PR 생성
  - merge with commit
